## 1 · What this module is about
Using open-source machine-learning frameworks (PyTorch, fastai and TensorFlow), you will learn the core principles of working with AI and apply them in Python to create research prototypes for creative purposes. You will train models for computer vision, text, tabular data and recommendations, and consider the ethical implications of your work throughout. 
### Unit learning objectives
#### LO1
Demonstrate detailed knowledge of contexts, concepts, technologies, skills, and processes in the creation of a defined project that uses cutting-edge artificial intelligence processes.
#### LO2
Demonstrate an understanding of a range of programming skills and workflows and present work in a professional manner appropriate to the audience and context. 
#### LO3
Create a body of work that demonstrates a consistent, refined, and ethical application of appropriate advanced programming, and machine learning processes. 
### The journey in four phases

| Weeks | Phase | What you will do |
|---------|---------|---------|
| 1–4 | Foundations | Python through creative coding; data and machine-learning basics; how neural networks learn |
| 5–11 | Core AI techniques | Image classification, object detection, text analysis and generation, recommenders, generative image and sound |
| 7 | Checkpoint | Pitch your project proposal and get feedback |
| 12–14 | Professional practice and realization | Polish your code and interface, test with users, showcase and submit |

## 2 · How each week works
Every week follows the same pattern, and every week on Moodle uses the same headings, so you always know where to look. 

| When | Session | What happens |
|--------|---------|---------|
| Before class | Pre-recorded materials | Watch Videos and Lecture Materials |
| In class | A · Technical demonstration | New concepts and live coding; type along |
| In class | B · Lab workshop | Build something creative in pairs (Core or Stretch tasks) |
| In class | C · Group seminar | Discussion, readings and debate about AI in creative practice |
| In class | D · Tutorial | Code clinic, feedback and project check-ins |
| After class | Independent study | Practice notebook, reading and portfolio work |
### Two tracks in every lab
- **Core** — edit and complete working code. Everyone starts here, and Core work is enough to do well.
- **Stretch** — write new code and extend the idea. Move on to Stretch when you finish Core.

## 7 · Ground rules
### In class and online
- Arrive on time with your laptop charged and the week's videos watched.
- Be respectful in discussion: evidence over opinion; challenge ideas, not people.
- Help your pair — explaining code is one of the best ways to learn it.
- Keep the Q&A forum professional and on topic.
### Academic integrity and AI tools
- You may use AI assistants to explain an error, suggest search keywords or check grammar and you must declare that use in your R&D document.
- You may not submit writing or code produced by AI as your own, invent sources or data, or submit code you cannot explain line by line.
- Reference every source using the UCA Harvard style. AI chatbots can invent references that look real and always check that a source exists and read it yourself.
- Use only data, images and sound you have the right to use. Get consent before photographing or recording people or their work.

## 8 · Key words you will meet in Week 1

| Term | Plain-English meaning |
|---------|---------|
| Artificial intelligence (AI) | Computer systems doing tasks we would call intelligent if a person did them |
| Machine learning (ML) | AI that learns patterns from examples instead of following hand-written rules |
| Deep learning | Machine learning using neural networks with many layers, good with images, sound and text |
| Model | What a machine-learning system learns: the "recipe" it uses to make predictions |
| Dataset | The collection of examples a model learns from |
| Python | The programming language we use; popular for AI and readable for beginners |
| Notebook (.ipynb) | A file that mixes code, output and notes; runs in Google Colab or JupyterLab |
| Cell | One block of a notebook; run it with Shift + Enter |
| Variable | A labelled box that stores a value, e.g. `artist = "Vera"` |
| Loop | Code that repeats, e.g. `for i in range(4):` |

## 9 · Frequently asked questions
### I have never coded. Will I be able to keep up?
Yes. Weeks 1–4 teach Python from the beginning through creative projects, every lab has a Core track, and you work in pairs. What matters most is attending, doing the weekly practice, and asking for help early. 
### Do I need a powerful laptop?
No. Heavy training runs in Google Colab, which provides free GPUs in the browser. Any laptop that can run a modern web browser is enough for most of the module. 
### Do I need to be good at maths?
No. We explain ideas visually and with analogies. You will use numbers, but the libraries do heavy maths. 
### Can my project be about my own discipline?
Yes, that is the point. The strongest projects connect AI to a real question in your own practice. 
### What if I miss a session?
Slides, notebooks and handouts are on Moodle each week. Work through them, post questions in the Q&A forum, and let your lecturer know.
